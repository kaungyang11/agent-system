# 代理商销售管理系统 - 系统架构设计

**设计日期**: 2026-05-07  
**预计开发周期**: 2周  
**目标**: 在线网站 + 算能NAS数据存储

---

## 一、系统角色定义

| 角色 | 描述 | 主要权限 |
|------|------|----------|
| 🏢 **算能管理员** | 系统最高管理员 | 用户管理、系统配置、全局数据、报表 |
| 👔 **销售** | 算能销售团队 | 客户管理、订单处理、业绩统计、跟进客户 |
| 🤝 **代理商** | 渠道合作伙伴 | 下单采购、管理下级客户、查看政策 |
| 🛒 **最终客户** | 产品购买者 | 浏览产品、下单购买、查看订单 |

## 六、业务规则 (2026-05-07 更新)

### 1. 库存约束规则

```
重要约束：销售/客户不能购买代理商未备货的产品
```

**业务流程**：

```
┌─────────────────────────────────────────────────────────────────┐
│                     库存约束流程                                 │
└─────────────────────────────────────────────────────────────────┘

     Step 1              Step 2              Step 3
  ┌──────────┐       ┌──────────┐       ┌──────────┐
  │ 代理商   │ ───►  │ 客户/    │ ───►  │ 订单     │
  │ 备货采购 │       │ 销售下单 │       │ 生成     │
  │ (MOQ)    │       │ 限购已有 │       │ 扣减库存 │
  └──────────┘       │ 库存     │       └──────────┘
                     └──────────┘

说明：
├── 代理商必须先向算能采购备货
├── 客户/销售下单时，只能选择代理商【有库存】的产品
├── 下单成功后，自动扣减代理商库存
└── 库存不足时，禁止下单
```

### 2. 业绩记录所需凭证

管理员记录业绩需要以下 **三样凭证**：

| 凭证类型 | 说明 | 上传方式 |
|----------|------|----------|
| 📄 **双章合同** | 最终客户和代理商签字盖章的合同 | PDF/图片上传 |
| 💳 **付款凭证** | 客户向代理商付款的凭证 | 截图/转账记录 |
| 📦 **发货凭证** | 代理商向客户发货的凭证 | 物流单/签收单 |

> 三证齐全 → 管理员审核 → 记录业绩 → 计算余额奖励

### 2. 代理商余额奖励机制

```
公式：余额 = 最终销售数量 × (LP - 0.9 × PDC)

其中：
  LP  = 算能向代理商的销售价格（List Price）
  PDC = 代理商向最终客户的销售价（Distributor Customer Price）
```

**示例计算：**

| 场景 | LP | PDC | 销售数量 | 余额计算 | 结果 |
|------|-----|-----|----------|----------|------|
| 正常 | ¥100 | ¥110 | 100件 | 100×(100-99)=100×1=**100元** | ✅ 赚100 |
| 正常 | ¥100 | ¥120 | 100件 | 100×(100-108)=**亏损** | ⚠️ PDC太低 |
| 高价 | ¥100 | ¥150 | 50件 | 50×(100-135)=**亏损** | ❌ 亏损 |

> 管理员需合理设置LP和PDC指导价，避免代理商亏损

### 3. 业绩分配建议流程

```
销售提出建议 ──► 管理员审核 ──► 确认生效 ──► 系统记录
```

- 销售可提出业绩归属分配方案（如A销售60%，B销售40%）
- 管理员审核通过/驳回/修改后生效
- 业绩归属确定后计入各销售业绩统计

## 七、需求确认清单

| 序号 | 问题 | 答案 |
|------|------|------|
| 1 | NAS网盘访问方式 | **WebDAV**（HTTPS公网访问） |
