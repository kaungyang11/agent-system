### 5.3 余额查询

| 用例编号 | 用例名称 | 测试步骤 | 预期结果 |
|----------|----------|----------|----------|
| AG-006 | 查看余额 | 进入代理商管理或API查询 | 显示当前余额 |
| AG-007 | 查看余额明细 | API查询 `/api/v1/agents/{id}/balance` | 显示余额变动记录 |

**余额计算公式**:
```
余额奖励 = 销售数量 × (LP价格 - 0.9 × PDC价格)
```

**示例**: 
- LP价格 = 1000元
- PDC价格 = 1200元
- 销售数量 = 10台
- 余额奖励 = 10 × (1000 - 0.9 × 1200) = 10 × (1000 - 1080) = -800元 ⚠️ 亏损

**正确示例**:
- LP价格 = 1000元
- PDC价格 = 1100元
- 销售数量 = 10台
- 余额奖励 = 10 × (1000 - 0.9 × 1100) = 10 × (1000 - 990) = 100元 ✅

## 七、业务流程Demo

### 7.1 完整业务流程Demo

```
┌─────────────────────────────────────────────────────────────────────┐
│                        业务流程Demo                                  │
└─────────────────────────────────────────────────────────────────────┘

Step 1: 管理员初始化
├── 创建产品: SE6盒子 (LP=1000, PDC=1100, MOQ=10)
├── 创建销售: sales1
├── 创建代理商: agent1 (初始余额=10000)
└── 创建客户: XX科技 (sales_id=1, agent_id=1)

Step 2: 代理商备货
├── agent1采购20台SE6盒子
└── 库存: agent1 -> SE6盒子 = 20台

Step 3: 客户下单
├── XX科技下单10台SE6盒子 (客单价=1100)
└── 库存: agent1 -> SE6盒子 = 10台

Step 4: 销售提交业绩
├── 填写业绩: 订单号、数量、LP/PDC价格
├── 上传凭证: 合同 + 付款凭证 + 发货凭证
└── 提交审核

Step 5: 管理员审核
├── 审核通过
└── 余额奖励 = 10 × (1000 - 0.9×1100) = 100元
    → agent1余额: 10000 + 100 = 10100元
```

### 7.2 API调用顺序Demo

```bash
# 1. 管理员登录
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "admin123"}'
# 返回 token

# 2. 创建产品
curl -X POST http://localhost:8000/api/v1/products \
  -H "Authorization: Bearer <token>" \
  -d '{"name": "SE6盒子", "code": "SE6", "lp_price": 1000, "pdc_price": 1100, "moq": 10}'

# 3. 代理商备货
curl -X POST http://localhost:8000/api/v1/inventory \
  -H "Authorization: Bearer <token>" \
  -d '{"agent_id": 1, "product_id": 1, "quantity": 20}'

# 4. 客户下单
curl -X POST http://localhost:8000/api/v1/orders \
  -H "Authorization: Bearer <token>" \
  -d '{"customer_id": 1, "agent_id": 1, "product_id": 1, "quantity": 10}'

# 5. 提交业绩
curl -X POST http://localhost:8000/api/v1/performance \
  -H "Authorization: Bearer <token>" \
  -d '{"order_id": 1, "sales_id": 1, "lp_price": 1000, "pdc_price": 1100, "quantity": 10}'

# 6. 审核业绩
curl -X PUT http://localhost:8000/api/v1/performance/1/approve \
  -H "Authorization: Bearer <token>"

# 7. 查看代理商余额
curl http://localhost:8000/api/v1/agents/1/balance \
  -H "Authorization: Bearer <token>"
```

## 十、注意事项

1. **JWT Token**: 所有API（除登录注册）都需要在Header中带 `Authorization: Bearer <token>`
2. **库存约束**: 下单时会检查代理商库存，不足则拒绝
3. **业绩审核**: 必须三证（合同、付款凭证、发货凭证）齐全才能通过
4. **余额公式**: `余额 = 数量 × (LP - 0.9 × PDC)`，结果可能为负数
